Academic Objective

My goal is to master the intricacies of network architecture and data transmission protocols to contribute to the development of secure, efficient, and high-speed global communication systems.

Topics Studied

1. Network Topologies

I studied Star, Bus, Ring, Mesh, Tree and Hybrid topologies. These topologies explain how devices connect in a network.

2. Error Detection

I learned about checksum, parity check, and cyclic redundancy check (CRC).

3. Transmission Media

I studied coaxial cable, fiber optic cable, twisted pair cable, and wireless communication systems.

4. OSI Model

The OSI model contains seven layers used in communication systems.

5. Routing and Switching

Routers and switches help transfer data between devices and networks.
